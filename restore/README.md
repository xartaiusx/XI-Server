# Mochirii Restore Assets

This folder contains Git-safe restore material only.

- `manifests/` records the current redacted Twills, database, Windower, mod, and
  verification state.
- `templates/` contains local settings examples that can be copied on a fresh
  clone.
- `artifacts/` is intentionally ignored except for its README. Put encrypted
  private payloads there only when intentionally staging a local restore.

Do not place plaintext database dumps, passphrases, Final Fantasy XI client
files, DAT files, mod archives, raw screenshots, or runtime logs in this folder.
